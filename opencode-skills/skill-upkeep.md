# Skill Upkeep (Opencode)

## Process
1. Identify repeated pain point or workflow inefficiency
2. Check existing skills for overlap
3. Prefer updating existing over creating new
4. Keep updates small and targeted
5. Ensure clear descriptions for triggering
6. Avoid bloating with one-off notes
