# PPTX Skill (Opencode)

## Quick Reference
- Read content: markitdown
- Edit: unpack -> edit XML -> pack
- Create from scratch: pptxgenjs

## Design Guidelines
- Pick a bold color palette - don't default to blue
- Dominance over equality: one color should dominate
- Every slide needs a visual element - text-only is boring
- Use interesting font pairings

## Common Palettes
- Midnight Executive: navy + ice blue + white
- Forest & Moss: forest + moss + cream
- Charcoal Minimal: charcoal + off-white + black
- Teal Trust: teal + seafoam + mint

## Avoid
- Plain title + bullets
- Center-aligned body text
- Low contrast
- Generic blue
- AI-generated aesthetics

## QA
- Convert to images for visual review
- Check for overlapping elements
- Verify text contrast
