# Theme Factory (Opencode)

## Usage
1. Show available themes
2. Ask user to choose
3. Apply selected theme

4. Modern Minimalist - Clean grayscale
5. Golden Hour - Rich autumnal
6. Arctic Frost - Cool winter
7. Desert Rose - Dusty sophisticated
8. Tech Innovation - Bold modern
9. Botanical Garden - Fresh organic
10. Midnight Galaxy - Dramatic cosmic

## Process
1. Read theme specifications
2. Apply colors and fonts consistently
3. Ensure proper contrast
4. Maintain visual identity
