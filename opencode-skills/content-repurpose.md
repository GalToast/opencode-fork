# Content Repurpose (Opencode)

## Overview
Turn one real event into multiple channel-specific drafts while keeping tone authentic and safe.

## Workflow
1. Confirm facts and boundaries
   - What is true, what is implied, what is private
   - Any orgs/people to anonymize
2. Define channels + tone
   - LinkedIn/blog, X thread, TikTok/Reels, Reddit PSA
   - Tone: warm/professional vs gritty/real
3. Core narrative
   - Hook -> buildup -> turning point -> lesson -> CTA
4. Drafts
   - LinkedIn/blog: 350-700 words
   - X: 6-10 posts
   - TikTok/Reels: 45-70s script
   - Reddit: short PSA
5. Safety checks
   - Avoid defamation; use "impersonators" language
   - Remove sensitive data (links, tokens, emails)

## Outputs
- 2-4 channel drafts
- Optional caption/hashtag ideas
