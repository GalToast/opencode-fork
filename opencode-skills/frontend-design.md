# Frontend Design (Opencode)

## Design Thinking

Before coding, understand the context and commit to a BOLD aesthetic direction:
- **Purpose**: What problem does this interface solve? Who uses it?
- **Tone**: Pick an extreme - brutalist, retro-futuristic, luxury, playful, industrial, etc.
- **Constraints**: Technical requirements (framework, performance, accessibility)
- **Differentiation**: What makes this memorable?

## Guidelines
- **Typography**: Choose distinctive fonts, not generic ones like Arial/Inter
- **Color**: Commit to cohesive aesthetic, sharp accents
- **Motion**: Use CSS animations, stagger reveals, hover states
- **Layout**: Unexpected asymmetry, overlap, diagonal flow, negative space
- **Details**: Gradients, textures, shadows, custom cursors

## Quality
- Production-grade and functional
- Visually striking and memorable
- Cohesive with clear aesthetic point-of-view
- Meticulously refined in every detail

## Avoid
- Generic AI aesthetics
- Overused fonts (Inter, Roboto, Arial)
- Clichéd purple gradients
- Predictable layouts
