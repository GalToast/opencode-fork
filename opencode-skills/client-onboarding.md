# Client Onboarding (Opencode)

## Overview
Use this to move a lead from interest to signed agreement + deposit + verified access, with a clean scope and kickoff plan.

## Workflow
1. Confirm basics
   - Client name, primary contact, email, phone, company/legal name
   - Project type, goals, deadline, budget range
2. Define scope (SOW-ready)
   - List included tasks + explicit exclusions
   - Identify risks/assumptions and dependencies
   - Set best-effort targets vs hard guarantees
3. Access requirements
   - Minimum access list (CMS, hosting, DNS/CDN, analytics)
   - Security rules (no passwords by email, temp accounts, MFA preferred)
4. Terms + start conditions
   - Payment terms (e.g., 50/50)
   - Warranty window (e.g., 30 days bug fix)
   - Start conditions: signed agreement + deposit + access
5. Communication plan
   - Cadence (weekly update email)
   - Primary channel (email)
6. Deliverables + acceptance
   - Define "done" and acceptance criteria
7. Prep sendables
   - Agreement + SOW PDFs
   - Access checklist
   - Short cover email

## Outputs
- SOW and agreement drafts (PDF)
- Access checklist
- Kickoff/cover email

## Decision points
- If scope changes -> use change order language
- If access not available -> pause start date
