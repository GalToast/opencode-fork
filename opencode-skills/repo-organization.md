# Repo Organization (Opencode)

## Placement rules
- Lead profiles live at leads/profiles/<range>/<id-slug>/profile.md
- Evidence files live at leads/profiles/<range>/<id-slug>/evidence/
- Disqualified leads live at leads/disqualified/<range>/<id-slug>/profile.md
- Outreach artifacts live under outreach/ (drafts, queues, logs, templates)
- Opportunity only leads live at notes/opportunity-leads.md
- Repo index lives at repo-index.md
- Repo memory lives at memory.md

## Process
1. Determine the correct destination before creating files.
2. Update repo-index.md when adding new top level documents or folders.
3. Avoid moving or renaming existing files without explicit approval.
4. Keep file names short and ASCII when possible.
