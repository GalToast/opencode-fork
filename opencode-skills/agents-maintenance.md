# Agents Maintenance (Opencode)

## Process
1. Read AGENTS.md before editing.
2. Add only durable operating rules and remove duplication.
3. Keep instructions concise and aligned with current workflows.
4. Do not move procedural steps into memory files.
5. Ask before adding any sensitive or privacy related instructions.

## Formatting

- Keep overall length minimal.
